```text

  → Train 12건 / Valid 4건 / Test 4건 분할
  → Train으로만 전처리 기준 학습

      문자: qa·summary를 원핫 인코딩

```

## 지금까지 연결한 개념

- **X/y:** X는 예측 시점에 아는 정보, y는 실제 결과입니다. 학습 때는 둘 다 사용하지만 예측에는 X만 줍니다. 예측용 변수가 반드시 원인일 필요는 없지만, 예측 시점에 이용할 수 있어야 합니다.
- **Train/Valid/Test:** 학습 / 개발 중 확인 / 최종 평가의 역할입니다. Train/Test 분할 후 Train 안에서 CV를 했다면 각 fold의 검증 부분이 Valid 역할을 합니다. 이번 기본 실습은 고정 분할이며 Test를 평가하지 않습니다.
- **fit/transform:** 기준을 계산해 기억하기 / 기억한 기준 적용하기입니다. CV에서도 각 회차의 학습 부분으로만 전처리를 fit해야 합니다.
- **원핫의 0/1:** 작업 종류에 해당하는지를 뜻합니다. 정답 y의 성공/실패와는 다른 의미입니다.
- **ColumnTransformer/Pipeline:** 열마다 다른 변환을 적용해 결합하기 / 여러 처리 단계를 순서대로 연결하기입니다.

## 결과를 해석할 때

`DummyClassifier(strategy="most_frequent")`는 Train에서 가장 많은 정답만 반복합니다. 입력별 실패 규칙을 배운 모델이 아닙니다. 전처리를 포함한 전체 실행 흐름을 확인하고, 이후 모델과 비교할 기준선을 만드는 실습입니다.

Valid 4건에서 실제 성공 3건·실패 1건을 모두 성공으로 예측하면 정확도는 **3/4 = 75%**입니다. 그러나 실제 실패 1건 중 찾아낸 것은 **0건**입니다. 높은 정확도만으로 실패 탐지에 유용하다고 판단할 수 없습니다. 작은 합성 데이터의 검증 결과이며 Test 성능이나 실제 서비스 성능을 의미하지 않습니다.
